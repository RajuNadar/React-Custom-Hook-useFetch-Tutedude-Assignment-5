# React Custom Hook – useFetch

A React project developed as part of **Tutedude Assignment 5** after completing the React module.

## Overview

This project demonstrates how to create and use a reusable custom hook (`useFetch`) to fetch API data and manage different request states in React.

## Features

- Reusable `useFetch` custom hook.
- Fetch product data using the Fetch API.
- Loading state management.
- Error handling.
- Dynamic product rendering.
- Responsive product grid layout.

## Technologies Used

- React.js
- JavaScript
- Tailwind CSS
- Fetch API

## React Hooks Used

- `useState` – Managing data, loading, and error states.
- `useEffect` – Handling API requests.
- `useCallback` – Memoizing the fetching function.

## Key Learning Outcomes

- Understanding custom hooks in React.
- Reusing logic across components.
- Handling asynchronous API requests.
- Managing loading and error states.
- Working with dynamic API data.

[EscuelaJS Fake Store API](https://api.escuelajs.co/api/v1/products)
